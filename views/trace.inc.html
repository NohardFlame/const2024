Библиотека созвездий

Выберите слот, затем откройте в редакторе или перенесите в другой класс.

Переносятся const + tex + имя; у источника имя очищается. Прежнее содержимое цели уходит в архив; достижения цели очищаются.

Архив

Перед перезаписью слота (сохранение / копирование) старое созвездие кладётся сюда.

Текущий слот цели тоже архивируется. Восстанавливаются const + tex + имя.

Предпросмотр доски

Сдвиг ((x+1)·0.65−0.3), колонка карточек слева. Звёзды = якоря, не ручки Безье.
