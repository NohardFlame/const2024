# Школьный зодиак — документация

Доска достижений для школьников: каждый класс — созвездие, каждое достижение — именованная звезда. Зритель выбирает класс, звёзды собираются в фигуру, у зажжённых звёзд появляются имя и текст достижения.

**Что сохраняем при любой переработке:** идея созвездий с именованными звёздами и поведение для зрителя (выбор класса → сборка фигуры → имя и достижение у звезды). Как это устроено под капотом — можно менять.

## Запуск

Проект — статический сайт на [p5.js](https://p5js.org/) (WEBGL). Для локального просмотра нужен HTTP-сервер: загрузка шейдеров и JSON с `file://` в браузере часто блокируется.

```bash
# из корня репозитория
python -m http.server 8765
```

Открыть в браузере:

| Страница | URL | Назначение |
| --- | --- | --- |
| Доска | `…/index.html` | Публичный просмотр; `N` — только локальные настройки |
| Вход | `…/login.php` | Пароль из `admin_auth` |
| Дефолты | `…/settings.php` | Туманность/стиль «для всех» (после входа) |
| Звёзды | `…/add_new_star.php` | Перетаскивание достижений + ручной синк |
| Обводка | `…/trace.php` | Исходник → `constN.json` + `texN.png` |

Локально для PHP-страниц нужен PHP (не только `python -m http.server`).

**Публичная доска:** `N` крутит localStorage; кнопки «сохранить для всех» убраны.

**Админка:** [`login.php`](../login.php) → сессия. Запись через [`JSONSaver.php`](../JSONSaver.php) / [`AssetSaver.php`](../AssetSaver.php) только с сессией.

**Таблица → сервер:** [`SheetSync.php`](../SheetSync.php) (cron каждые 5 мин или кнопка в редакторе). Ключ `sync_key` в [`admin_auth`](../admin_auth.example). Сессия админа тоже подходит (без ключа в URL).

Схема листов (детерминированный синк):

| Лист | Заголовок | Текст | Публикация |
| --- | --- | --- | --- |
| `* класс` | столбец **C** | столбец **B** | столбец `опубликовать` (обычно **D**, Checkbox) |
| `* инд` | столбец **Итог** | столбец **текст звезды** | столбец **опубликовать** (Checkbox) на строке с номером группы |

В синк попадают только строки с активной галочкой. При одном `starId` на класс- и инд-листе побеждает класс. Чеклист колонок — в [deploy.md](deploy.md).

**Обводка / звёзды** — только после входа; старые `.html` редиректят на `.php`.

## Структура репозитория (кратко)

```
index.html              # доска
add_new_star.html       # редактор
JSONSaver.php           # запись JSON на диск (редактор звёзд / style_defaults)
AssetSaver.php          # запись constN + texN + animal + архив (обводка)
trace.html              # редактор обводки
assets/archive/         # снимки слотов до перезаписи
assets/js/
  main.js               # жизненный цикл p5
  options.js            # dataHandler — состояние и отрисовка
  make_a_texture.js     # предрасчёт кадров морфа
  svg_parser.js         # офлайн-генератор вершин из SVG
  svg_points.js         # парсинг path / дедуп / Безье-хелперы
  trace_editor.js       # UI обводки
  add_new_star.js       # логика редактора звёзд
  sheet_import.js       # разбор CSV (вспомогательный)
  interface_handler.js  # устаревшие хелперы (частично не используются)
AdminAuth.php / login.php / logout.php / settings.php
add_new_star.php / trace.php
views/                  # HTML редакторов (закрыт .htaccess)
SheetProxy.php          # прокси CSV
SheetSync.php           # синк таблицы → constN.json (sync_key или сессия)
assets/json/            # const0.json … const9.json, classes.json
assets/textures/        # силуэты texN.png, атлас классов, звезда
assets/shaders/         # GLSL ES 3.00
```

## Индексы созвездий

- **0–8** — девять классов (клетки сетки 2¹…4³ внизу слева).
- **9** — домашний экран: здание лицея и заголовок «Школьный зодиак …» в `tex9.png`. Собирается при загрузке; отдельной клетки в сетке нет; панель достижений для него скрыта.

Соответствие индекс ↔ животное / текстура задаётся файлами `constN.json` и `texN.png` (см. [data-model.md](data-model.md)).
